# 📈 DOPAMING STOCK BOT

**Dopaming Stock Bot**은 키움증권 OpenAPI+ 기반으로 설계된 100% 자동화 주식 트레이딩 데스크톱 애플리케이션입니다. 1분봉 및 5분봉 등 다중 타임프레임을 활용한 **스테파노 전략(RSI 다이버전스)**을 시스템화하여 완전 자율 주행으로 매수와 매도(익절/손절)를 수행하며, 모던하고 깔끔한 UI(Toss/Kakao 벤치마킹)의 대시보드를 제공합니다.

---

## 🛠️ 주요 기능 (Features)

- **키움증권 OpenAPI+ 연동**: 모의투자와 실제 운영 계좌를 모두 지원합니다. (초당 5회 API 호출 제한 완벽 대응 스로틀링 구현)
- **스테파노 다이버전스 전략 봇 자동화**: 거시 타임프레임(5분봉)과 미시 타임프레임(1분봉)의 RSI를 교차 추적하여 다이버전스를 발견할 시 자동으로 시장가 진입(매수)합니다.
- **자동 포지션 청산 관리 매니저**: 하락 시 기계적인 -2% 손절, 상승 시 +4% 익절 룰에 따라 자동 시장가 청산을 수행합니다.
- **모던 데스크톱 UI 대시보드 (Toss/Kakao 벤치마킹 디자인)**:
    - 실시간 로그 추적 (직관적 하이라이트 기능 내장)
    - 감시 중인 종목 리스트 1순위 상단 자동 정렬 기능
    - 실계좌/모의계좌 잔고 및 오픈 포지션의 실시간 손익률 연동 현황판 제공
- **백그라운드 통신**: 체결 현황 및 슬랙(Slack) 메시지 자동 발송 알림 연동 기능.

## 💻 시스템 요구사항 (Requirements)

키움증권 API 구조상 **반드시 32비트(32-bit) 구동 환경**이 필수적입니다.
본 환경이 맞지 않으면 64비트 오류 호환성 충돌이 발생합니다.

- **OS:** Windows 10 / 11 환경 전용 (키움증권 OpenAPI 자체가 MacOS 지원 불가)
- **키움증권 OpenAPI+ 모듈 설치 완료 상태** (KOAStudio 연동 확인)

## 🚀 설치 및 시작 가이드 (Installation & Setup)

### 1단계: 저장소(Repository) 클론 및 준비
```bash
git clone https://github.com/MING-beta/DOPAMING-STOCKBOT.git
cd DOPAMING-STOCKBOT
```

### 2단계: 환경 변수 설정(`.env` 파일)
프로젝트 최상단 경로(`Dopaming-Stock-Bot/`)에 있는 `.env.template` 파일을 복사하여 `.env`로 이름을 변경하고 내부 값을 채워 넣으세요.
* `ACCOUNT_PASSWORD`: 키움증권 계좌 비밀번호 (모의투자 시 주로 0000)
* `DRY_RUN_MODE`: `True` 이면 실제 매매 파이프라인에서 주문을 넣지 않는 시뮬레이션 모드로 작동합니다.
* `SLACK_WEBHOOK_URL`: (선택) 외부 슬랙 채널과 연동할 웹훅 주소

**(중요 가이드) 계좌 비밀번호 사전 등록**
봇이 화면 잠금 없이 무인으로 로그인 및 주문 정보를 열람하기 위해서는 `계좌 비밀번호 저장`이 필수적입니다.
1. 프로그램 실행 전, 윈도우 우측 하단 (시계 옆) 시스템 트레이에서 붉은색 **[A] 키움 OpenAPI 아이콘** 우클릭
2. **[계좌비밀번호 저장]** 클릭
3. 여러분의 로그인 계좌 목록을 체크한 후 비밀번호(모의투자는 0000)를 입력 후 `등록`

### 3단계: 봇 실행
키움증권은 32비트 환경이 절대적으로 강제되기 때문에 사용자가 로컬 파이썬 버전을 신경쓰지 않아도 되도록 **자동 실행 파일**을 내장시켜 두었습니다.
프로젝트 루트 디렉토리 안에 있는 바로가기 스크립트를 더블클릭 하세요.

📌 **`start_bot.bat` 파일 실행**

**실행 과정 요약:**
1. 프로젝트의 내장 `venv32` 파이썬 경로를 자동으로 인식하여 활성화.
2. 32비트 권한 및 필수 라이브러리 체크업.
3. 시스템 데스크톱 대시보드 창 팝업 및 자동 트레이딩 연동.

## 🧑‍💻 프로젝트 주요 구조 (Architecture)
프로젝트는 결합도 절감을 위해 고성능 모듈화(Modularization)가 적용되어 있습니다.

```text
Dopaming-Stock-Bot/
├── core/
│   ├── api_throttler.py      # OpenAPI 1초당 5회 제한 극복을 위한 비동기 메시지/주문 처리 큐
│   ├── data_pipeline.py      # 고속 실시간 틱(Tick) 수신 및 1분, 5분봉 등 다중 데이터 파이프라인 
│   ├── event_handlers.py     # OpenAPI TR 및 실시간 체결 등의 막대한 서버 응답 이벤트 라우팅
│   ├── execution_manager.py  # 전략 모듈의 계산에 의한 매수/익절/손절 주문 및 실제 잔고 동기화
│   └── kiwoom_core.py        # 세션 연동 메인 백본 및 시스템 로드 (Fallback Mock 우회 기능 내장)
├── strategy/
│   └── stefano_strategy.py   # 다이버전스와 저점 간섭(Valley)을 탐지하는 퀀트 전략 로직 엔진
├── ui/
│   └── dashboard.py          # Toss 계열 최신 다크 테마 방식의 정보 모니터링 데스크톱 클라이언트
└──  start_bot.bat            # 운영체제의 32비트 인터프리터 자동 추적 실행파일
```

## ⚠️ 라이선스 및 면책 조항
본 프로그램은 알고리즘 및 트레이딩 자동화 로직 학습용으로 개발된 저장소입니다.
실제 구동 중 발생할 수 있는 금전적인 포지션, 손실, 알고리즘 연산 버그에 대해 개발자는 어떠한 법적 및 금전적 책임을 지지 않습니다. 운영 환경(Production) 도입 전에 필히 `DRY_RUN_MODE=True`를 이용해 가상 테스트 및 모의투자를 선행하십시오.

## 🛠️ 문제 해결 (Troubleshooting)

**1. 키움 API `opversionup` 183 삭제 실패 에러 창이 계속해서 뜨는 경우**
- **원인**: 백그라운드에 봇 프로그램(또는 다른 키움증권 관련 봇/HTS)이 이미 몰래 실행되어 있어, 키움증권 모듈이 파일(`ocx`, `dll`)을 업데이트(덮어쓰기)하지 못해 발생하는 권한 차단 문제입니다.
- **해결**: `start_bot.bat` 파일 내에 봇이 켜지기 전 기존 파이썬 프로세스를 강제로 닫는 스크립트가 내장되어 있으므로 **배치 파일을 통해 정상적으로 실행**하면 대부분 해결됩니다. 안될 경우, 작업 관리자에서 `ncupdate.exe`, `opversionup.exe`, `python.exe` 등의 찌꺼기 프로세스를 수동으로 종료하세요.

**2. 실행 시 `A module that was compiled using NumPy 1.x cannot be run in NumPy 2.x` 에러**
- **원인**: 키움증권 32비트 환경에 맞춰 빌드된 Pandas(2.0.x) 바이너리가 최신 NumPy(2.x) 버전과 호환되지 않는 충돌 문제입니다.
- **해결**: 현재 `requirements.txt`에 호환되는 버전(`numpy<2.0.0`)으로 제한을 걸어두었습니다. 가상환경(venv32)을 새로 구성할 경우 에러 없이 구동됩니다.
