# 📈 DOPAMING-STOCK-BOT v2.6
**Dopaming-Stock-Bot**은 키움증권 OpenAPI+ 기반으로 설계된 **하이엔드 자율주행 주식 트레이딩 시스템**입니다. 서버급 고속 처리 기술과 병렬 연산 엔진을 탑재하여 찰나의 기회를 포착하며, 프리미엄 대시보드와 지능형 리포팅을 통해 트레이딩의 모든 순간을 시각화합니다.

---

## 🚀 설치 및 가동 가이드 (Installation & Setup)

> [!IMPORTANT]
> **필수 요구사항**: 본 프로그램은 키움 API 구조상 반드시 **Windows 10/11 64bit 환경**에 설치된 **Python 3.10.x 32-bit** 환경에서 구동되어야 합니다.

### 1단계: 키움 OpenAPI+ 상세 설정 (Kiwoom API Setup)
봇을 가동하기 전, 아래 과정을 통해 키움 API 환경을 먼저 완성해야 합니다.

1. **OpenAPI+ 모듈 설치**: [키움증권 공식 홈페이지](https://www1.kiwoom.com/h/m/home/Main) > 전체메뉴 > OpenAPI > 오픈API 소개 > [오픈API 서비스 시작하기]를 통해 모듈을 설치합니다.
2. **모의투자 신청 (필수)**: 
    - 영웅문4 HTS 접속 > 모의투자 탭에서 신청하거나, 홈페이지의 [상시모의투자 신청] 메뉴를 이용하십시오.
    - 신청 완료 후 모의투자용 비밀번호(`0000` 등)를 반드시 확인하세요.
3. **로그인 창 자동화 설정 (Tip)**:
    - 처음 봇을 실행하여 로그인 창이 뜨면 정보를 입력하고 로그인합니다.
    - 시스템 트레이(우측 하단)의 **키움 아이콘** 우클릭 > [계좌비밀번호 저장] 선택.
    - 계좌 비밀번호를 입력하고 **[전체계좌에 등록]** 및 **[자동로그인]**을 체크하세요. 이후부터는 로그인 창 없이 즉시 가동됩니다.

### 2단계: 영웅문4 대상종목(조건식) 설정 (Target Stocks)
우리 봇은 영웅문4 HTS에 저장된 **[내조건식]** 목록을 가져와 실시간으로 종목을 이탈/편입하며 감시합니다.

1. **조건검색 메뉴 진입**: 영웅문4 상단 메뉴 검색창에 **[0150]**을 입력하여 '조건검색' 창을 엽니다.
2. **조건식 작성**: 원하는 기술적 분석 지표(RSI, 가격대, 거래량 등)를 조합하여 전략을 구성합니다.
3. **내조건식 저장**: 
    - 작성 완료 후 **[내조건식 저장]**을 눌러 이름을 지정합니다 (예: `스테파노A`).
    - 저장된 조건식은 반드시 **서버에 저장**된 상태여야 봇이 인식할 수 있습니다.
4. **봇 자동 감시**: 봇을 실행하면 저장된 조건식에 해당하는 종목들이 자동으로 실시간 감시 목록에 포함됩니다.

### 3단계: 저장소 클론 및 가상환경 구축
```bash
# 저장소 클론
git clone https://github.com/MING-beta/DOPAMING-STOCKBOT.git
cd DOPAMING-STOCKBOT

# 32비트 파이썬을 이용한 가상환경 생성 (venv32)
python -m venv venv32
.\venv32\Scripts\activate

# 의존성 패키지 설치
pip install -r requirements.txt
```

### 4단계: 환경 변수 설정 (`.env`)
`.env.template`을 복사하여 `.env` 생성 후 아래 핵심 항목을 설정합니다.
- `DRY_RUN_MODE`: `True` (테스트 전용) / `False` (실전 매매)
- `SLACK_WEBHOOK_URL`: 리포트 수신용 슬랙 웹훅 주소
- `TRADE_INVEST_RATE`: 종목당 투자 비중 (총 자산 대비 %, 기본값 `0.05`)

### 5단계: 시스템 가동
가장 안정적인 실행을 위해 **`start_bot.bat`** 파일을 활용하십시오.
1. `start_bot.bat` 마우스 우클릭 -> **[관리자 권한으로 실행]**
2. **관리자 권한**은 API 버전 업데이트 및 라이브러리 접근을 위해 반드시 필요합니다.

## ✨ v2.6 핵심 고도화 (Main Features)

### 1. ⚡ 초저지연 스캘핑 가속기
- **우선순위 스로틀러**: 주문 발송(P0)이 데이터 요청(P2)을 즉시 추월하는 **0.2초 이내의 고속 진입로**를 확보했습니다.
- **병렬 분석 엔진**: 17개 이상 종목을 백그라운드 워커에서 동시에 분석하며, 연산 오버헤드를 90% 차단하는 지표 캐싱을 적용했습니다.

### 2. 💎 프리미엄 대시보드 2.0
- **Modern Dark UI**: 고유의 '슈퍼 라운딩' 디자인 파스텔 톤 다크 모드 적용.
- **실시간 리스크 보드**: 손실 제한 한도와 실시간 수익률을 매칭하여 시각적 비주얼 지표를 제공합니다.

### 3. 📊 지능형 수익 리포팅
- **데일리 워크쓰루**: 매일 15:30 장 종료 시 승률, 실현 손익 분석 리포트를 자동 생성하여 슬랙으로 모바일 전송합니다.

## 🏗️ 프로젝트 구조 (Architecture)

```text
Dopaming-Stock-Bot/
├── core/
│   ├── api_throttler.py      # 우선순위 기반 고속 요청 관리
│   ├── execution_manager.py  # 스레드 안전 주문 실행 및 리스크 컨트롤
│   ├── kiwoom_core.py        # API 백본 및 실시간 엔진
│   └── persistence.py        # SQLite 기반 거래 내역 영속화
├── strategy/
│   └── stefano_strategy.py   # 캐싱 기반 RSI 다이버전스 알고리즘
├── ui/
│   └── dashboard.py          # 프리미엄 다크 테스크탑 대시보드
└── utils/
    ├── report_generator.py   # 성과 분석 리포트 생성 엔진
    └── notifier.py           # 슬랙 클라우드 알림 허브
```
