# 📈 DOPAMING STOCK BOT

**Dopaming Stock Bot**은 키움증권 OpenAPI+ 기반으로 설계된 100% 자동화 주식 트레이딩 데스크톱 애플리케이션입니다. 1분봉 및 5분봉 등 다중 타임프레임을 활용한 **스테파노 전략(RSI 다이버전스)**을 시스템화하여 완전 자율 주행으로 매수와 매도(익절/손절)를 수행하며, 모던하고 깔끔한 UI의 대시보드와 강력한 슬랙(Slack) 알림 시스템을 제공합니다.

---

## 🛠️ 주요 기능 (Features)

- **키움증권 OpenAPI+ 연동**: 모의투자와 실제 운영 계좌를 모두 지원합니다. (초당 5회 API 호출 제한 완벽 대응 스로틀링 구현)
- **스테파노 다이버전스 전략 봇 자동화**: 거시 타임프레임(5분봉)과 미시 타임프레임(1분봉)의 RSI를 교차 추적하여 다이버전스를 발견할 시 자동으로 시장가 진입(매수)합니다.
- **동적 종목 모니터링 (Dynamic Monitoring)**: 실시간 조건검색식 편입/이탈 이벤트를 추적하여 감시 종목을 실시간으로 업데이트하며, 이탈 종목은 메모리에서 즉시 제거하여 효율적인 자원 관리를 수행합니다.
- **자동 포지션 청산 관리 매니저**:
    *   **익절/손절**: 하락 시 -2% 손절, 상승 시 +4% 익절 룰에 따라 자동 청산.
    *   **미체결 관리**: 주문 후 60초간 체결되지 않을 경우 자동으로 주문을 취소하여 미체결 주문이 유지되는 위험을 방지합니다.
- **강력한 슬랙(Slack) 푸시 메시지 알림**:
    *   **시스템 상태**: 봇 시작/종료 알림.
    *   **시장 스케줄**: 장 시작(09:00) 및 장 종료(15:30) 자동 알림.
    *   **헬스 체크**: 1분 단위로 API 서버 연결 상태를 점검하여 이상 발생 시 긴급 알림 발송.
    *   **거래 알림**: 매수/매도 주문 및 실제 체결 내역 실시간 전송.
    *   **경고 알림**: 미체결 타임아웃 발생 및 자동 취소 시 알림.
- **백그라운드 최적화 실행**: `start_bot.bat`을 통해 관리자 권한 강제 획득, 한글 깨짐 방지(UTF-8), 콘솔 창 숨김 모드 실행을 지원합니다.

## 💻 시스템 요구사항 (Requirements)

키움증권 API 구조상 **반드시 32비트(32-bit) 구동 환경**이 필수적입니다.

- **OS:** Windows 10 / 11 환경 전용 (관리자 권한 필수)
- **Python:** 3.10.x 32-bit 버전 (venv32 내장)
- **키움증권 OpenAPI+ 모듈 설치 완료 상태**

## 🚀 설치 및 시작 가이드 (Installation & Setup)

### 1단계: 저장소(Repository) 클론 및 준비
```bash
git clone https://github.com/MING-beta/DOPAMING-STOCKBOT.git
cd DOPAMING-STOCKBOT
```

### 2단계: 환경 변수 설정(`.env` 파일)
프로젝트 최상단 경로에 있는 `.env.template` 파일을 복사하여 `.env`로 이름을 변경하고 내부 값을 채워 넣으세요.
* `SLACK_WEBHOOK_URL`: 슬랙 채널 웹훅 주소 (필수 추천)
* `DRY_RUN_MODE`: `True` (시뮬레이션 모드), `False` (실전 매매/모의투자 주문 발송)

### 3단계: 봇 실행
📌 **`start_bot.bat` 파일 우클릭하여 실행** (자동으로 관리자 권한을 요청합니다)

**실행 시 혜택:**
1. **관리자 권한 자동 적용**: API 업데이트 및 레지스트리 접근 오류 방지.
2. **백그라운드 모드**: 터미널 창 없이 백그라운드(`pythonw`)에서 조용히 실행됩니다.
3. **인코딩 최적화**: 콘솔 로그의 한글 깨짐 현상을 방지합니다.

## 🏗️ 프로젝트 주요 구조 (Architecture)

```text
Dopaming-Stock-Bot/
├── core/
│   ├── api_throttler.py      # API 호출 제한(1초 5회) 관리를 위한 스로틀링
│   ├── data_pipeline.py      # 실시간 틱 데이터 리샘플링 및 메모리 관리
│   ├── event_handlers.py     # TR/실시간/조건검색 이벤트 라우팅 및 동적 종목 관리
│   ├── execution_manager.py  # 주문 실행, 미체결 타임아웃, 손익절 모니터링
│   └── kiwoom_core.py        # API 메인 백본 및 실시간 감시 엔진
├── strategy/
│   └── stefano_strategy.py   # RSI 다이버전스 분석 알고리즘
├── utils/
│   └── notifier.py           # 슬랙 웹훅 알림 (동기/비동기 지원)
└── test_trade.py             # 매매 로직 검증을 위한 8가지 통합 테스트 케이스
```

## 🛠️ 문제 해결 (Troubleshooting)

**1. 키움 API `opversionup` 183 삭제 실패 에러**
- **해결**: 모든 파이썬 프로세스와 키움 모듈을 종료해야 합니다. `start_bot.bat`은 실행 시 자동으로 기존 고스트 프로세스를 정리한 후 관리자 권한으로 실행되므로, 배치 파일을 통해 실행하면 대부분 해결됩니다.

**2. 슬랙 알림이 오지 않는 경우**
- **원인**: `.env`에 `SLACK_WEBHOOK_URL`이 정확히 입력되지 않았거나 인터넷 연결에 문제가 있을 수 있습니다.
- **해결**: 웹훅 URL 형식을 확인하고, `utils/notifier.py` 단독 실행 테스트를 권장합니다.
