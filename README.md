# 📈 DOPAMING-STOCK-BOT v2.6
**Dopaming-Stock-Bot**은 키움증권 OpenAPI+ 기반으로 설계된 **하이엔드 자율주행 주식 트레이딩 시스템**입니다. 서버급 고속 처리 기술과 병렬 연산 엔진을 탑재하여 찰나의 기회를 포착하며, 프리미엄 대시보드와 지능형 리포팅을 통해 트레이딩의 모든 순간을 시각화합니다.

---

## ✨ v2.6 핵심 고도화 (Main Features)

### 1. ⚡ 초저지연 스캘핑 가속기 (Extreme Performance)
- **우선순위 스로틀러 (Priority Throttler)**: 주문 발송(P0)이 모든 데이터 요청(P2)을 즉시 추월하도록 설계하여 **0.2초 이내의 즉각적인 시장 진입**로를 확보했습니다.
- **병렬 분석 엔진 (Parallel Engine)**: 17개 이상의 감시 종목을 백그라운드 워커 스레드에서 동시에 0.5초 주기로 정밀 분석합니다.
- **지능형 지표 캐싱 (Indicator Caching)**: 신규 캔들 생성 시에만 연산을 수행하는 증분 계산 방식을 도입하여 **CPU 점유율 90% 절감**과 속도 향상을 동시에 달성했습니다.

### 2. 💎 프리미엄 대시보드 2.0 (High-End UI/UX)
- **Modern Dark Theme**: 세련된 파스텔 톤 다크 모드와 고유의 '슈퍼 라운딩' 디자인 언어를 적용하여 장시간 사용에도 피로도가 적은 UI를 제공합니다.
- **동적 리스크 보드**: 설정된 손실 제한 한도와 실시간 수익률을 매칭하여 시각적 경고 및 자산 현황을 직관적으로 전달합니다.
- **반응형 감시 테이블**: 종목별 분석 상태, RSI 흐름, 등락 여부를 아이콘과 프로그레스바로 시각화하여 정보 가독성을 극대화했습니다.

### 3. 📊 지능형 수익 리포팅 시스템 (Performance Analytics)
- **데일리 워크쓰루 자동 생성**: 매일 장 종료(15:30) 시 당일 승률, 실현 손익, 최고/최악 종목 랭킹을 포함한 상세 마크다운 리포트를 자동 생성합니다.
- **슬랙(Slack) 클라우드 연동**: 생성된 정밀 리포트는 슬랙 웹훅을 통해 스마트폰으로 즉시 전송되어 언제 어디서든 당일 성과를 확인할 수 있습니다.

### 4. 🛡️ 서버급 무결성 및 안정성 (Architecture)
- **Thread-Safe 디자인**: 멀티스레드 환경의 데이터 경합을 완벽히 방어하기 위해 공유 자원 전 영역에 `threading.Lock` 보호 체계를 갖추었습니다.
- **다중 리스크 가드**: 하드 손절(-2%), 트레일링 스톱(Trailing Stop), 당일 총자산 대비 최대 손실 차단 등 다중 방어 메커니즘을 가동합니다.

## 🚀 빠른 시작 가이드 (Quick Start)

### 1단계: 환경 설정 (`.env`)
`.env.template`을 복사하여 `.env`를 생성하고 다음 항목을 입력하세요.
- `SLACK_WEBHOOK_URL`: 리포트 수신용 슬랙 웹훅 URL
- `DRY_RUN_MODE`: `False` (실전 매매), `True` (가상 체결 테스트)

### 2단계: 최적 실행
📌 **`start_bot.bat` 실행** (자동 관리자 권한 및 UTF-8 최적화)
- 실거래 전 반드시 `test_trade.py`를 실행하여 13가지 핵심 매매 알고리즘의 작동 여부를 검증하십시오.
