**Dopaming-Stock-Bot**은 키움증권 OpenAPI+ 기반의 **전문가용 고빈도 자율주행 주식 트레이딩 데스크톱 플랫폼**입니다. 단순한 조건 검색 매매를 뛰어넘어, 초저지연(ApiThrottler) 병렬 통신과 5중 다중 전략(Multi-Strategy), 그리고 실시간 머신러닝 AI 엔진이 결합되어 인간의 한계를 초월하는 실전 스캘핑 성능을 자랑합니다.

## 🚀 주요 하이라이트 (Key Highlights)

- **ApiThrottler (통신 방위군)**: 키움증권의 초당 5회 한도를 정확히 제어하여 계좌 정지 위협 0%. 10ms 딜레이 구동 환경에서도 3.3tps(300ms) 방어를 통해 최대치인 80~100개 종목을 셧다운 없이 동시 관제합니다.
- **다중 전략 엔진 (Multi-Strategy Engine)**: 단일 지표에 의존하지 않고 돌파(Breakout), 눌림목(Pullback), 인내결실(Patience), AI 스나이퍼 등 5가지 독립된 전략이 동시에 평가되어 교차 검증된 최적의 타점에서만 진입을 승인합니다.
- **오토 백업 및 힐링 (Auto-Healing)**: 통신 지연이나 일시적 오류로 차트 데이터가 누락될 경우 봇이 스스로 오류를 감지하고 서버에 틱을 재요청하여 자가 복구합니다.
- **100% 라이브 서버 수익 기반 연동**: 봇 내부의 허위 PnL이 아닌, 키움 수수료 및 세금이 100% 차감된 공식 서버 실현손익 데이터(opt10085)를 장부 메인으로 채택했습니다.

## 📉 다중 전략 엔진 (Multi-Strategy Engine)

봇은 모든 1분 캔들 틱이 유입될 때마다 병렬로 아래의 전략 풀을 가동합니다:

1. 🚀 **강세 돌파 (Breakout)**: 볼린저 밴드 상단을 강하게 돌파하면서 매수세(거래량 비율 650% 초과)가 터지는 극초반 가속 구간 타격.
2. 🌊 **안전 눌림목 (Pullback)**: 급등 이후 거래량이 급감하며 볼린저 중심선 부근에서 지지받는 최적의 반발 매수 타이밍 포착.
3. 🤖 **AI 스나이퍼 (AI Sniper)**: LightGBM이 10여 개의 지표를 결합하여 최근 장세 패턴에 대조 후 승률 38%(`AI_THRESHOLD=0.38`)를 넘기는 공격적 포지셔닝.
4. 🌍 **거시 추세 (Macro KIWI)**: 단편적인 1분봉의 함정에 속지 않고, 병렬 백그라운드 5분봉 스캐너를 융합 판단.
5. 💤 **인내 결실 (Patience)**: 극단적인 투매가 발생한 과매도 웅덩이에서의 기술적 반등 흡수.

## 🚀 설치 및 자동화 세팅 (Installation & Setup)

> [!WARNING]
> 본 프로그램은 64비트 파이썬에서는 작동하지 않습니다! 키움증권 DLL 제약이 있으므로 무조건 **Python 32-bit** 버전을 설치해야 합니다.

### 1단계: 개발자 세팅 및 인증
1. 키움증권 공식 홈페이지에서 **오픈API 서비스 사용 신청**.
2. Python 3.10 (32-bit) 설치.
3. 해당 리포지토리를 클론(Clone) 합니다.
```bash
git clone https://github.com/heroq/DOPAMING-STOCK-BOT.git
cd DOPAMING-STOCK-BOT

# 가상환경 구축 (필수)
python -m venv venv32
.\venv32\Scripts\activate
pip install -r requirements.txt
```

### 2단계: 환경 변수 (.env) 튜닝
프로젝트 루트 폴더의 `.env.template` 파일을 복사하여 `.env`로 이름을 바꾼 뒤 수치를 조정합니다. (스캘핑 권장치 적용 완료)
```env
# 운영체제/모드
DRY_RUN_MODE=True            # 실제 주문 차단 여부 (안전용으로 True 필수)
ACCOUNT_PASSWORD=0000        # 모의투자(0000) 또는 실거래 비밀번호
SLACK_WEBHOOK_URL=https://hooks.slack.com/services/T000... # 봇 알림 수신처 설정

# 봇 파라미터 셋업
MAX_MONITORED_STOCKS=80      # 황금 관제 밸런스 (서버 부하 없이 매수 기동 극대화)
TRADE_INVEST_RATE=0.99       # 종목당 배정 예산 무시 (가용 금액 풀매수 공격형 돌진)
TRADE_TARGET_PROFIT=0.021    # 기본 2.1% 스캘핑 익절 커트
TRADE_STOP_LOSS=-0.020       # 최대 -2.0% 철제 손절 커트
STRATEGY_SIGNAL_COOLDOWN=300 # 거래 쿨타임 (5분)

# 인공지능 세팅
AI_THRESHOLD=0.38            # 38% 이상의 공격적인 승률을 AI가 판단 시 허가 
```

### 3단계: 키움 API 및 조건검색 연계 작동
영웅문(HTS)의 `[0150] 조건검색` 화면을 켜고 원하는 주도주/수급주 검색식을 만들어 서버에 저장(`v11조건식`)해 두면 봇이 자동으로 해당 종목들을 관제 풀(Pool)로 끌고 옵니다. 
이제 터미널을 열고 봇을 가동하세요!
```bash
python main.py
```

## ⚠️ 라이선스 & 법적 면책 사항
